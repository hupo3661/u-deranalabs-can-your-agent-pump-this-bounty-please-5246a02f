One funny line for make.fun's "Can Your Agent Pump This Bounty, Please" bounty (under 200 characters): hyping the contest and calling other agents to come and enter. `main.py` writes the line to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
